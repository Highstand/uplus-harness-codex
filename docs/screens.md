## 요금제 목록

### 목적
무제한 유형 필터로 요금제 후보를 좁히고, 각 요금제의 유형·데이터 조건·매달 내는 돈을 비교한다. US1, US2를 해결한다.

### 라우트
`/plans`

### 구성 요소
- Header — 제목과 보조 문구
- FilterChip — `전체` / `기본형` / `무제한 · 속도 제한 있음` / `완전 무제한`
- icon/check — 선택된 FilterChip 표시
- Card/Plan — 요금제 이름, 유형, 데이터, 소진 후 속도, 금액, 한 줄 설명
- Tag — 요금제 유형과 p03의 `추천` 표시
- 신규: Plan Card Skeleton — 목록 로딩 자리 표시자
- 신규: Empty State — 검색 결과 없음 안내
- 신규: Inline Error — 목록 조회 실패 안내
- Button — 목록 다시 불러오기

### 상태
- 기본: `전체`가 선택되고 p01 → p02 → p03 → p04 순서로 카드 4개를 표시한다. p03에만 `추천` Tag를 표시한다. 카드에는 `매달 내는 돈`과 `24개월 후 월 요금`만 표시한다.
- 로딩: FilterChip 조작을 막고 Plan Card Skeleton 4개를 표시한다.
- 빈: 선택 유형의 결과가 없으면 `이 유형의 요금제가 없어요.`를 표시한다.
- 에러: `요금제를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`와 다시 불러오기 Button을 표시한다.

### 이동
- 들어오는 곳: 서비스 최초 진입, 요금제 상세, 변경 전 확인, 신청 완료
- 나가는 곳: Card/Plan 선택 → 해당 `planId`의 요금제 상세

## 요금제 상세

### 목적
선택한 요금제의 요금 구성, 24개월 후 월 요금, 기본 데이터 소진 후 속도 조건을 확인한다. US2, US3을 해결한다.

### 라우트
`/plans/:planId`

### 구성 요소
- Header — 화면 제목
- icon/arrowLeft — 요금제 목록으로 돌아가기
- Card/Plan — 요금제 이름, 유형, 추천 여부, 매달 내는 돈, 24개월 후 월 요금
- Tag — 요금제 유형과 추천 표시
- Card/Price — 정가, 24개월 할인, 매달 내는 돈
- List/Row — 기본 데이터량, 소진 후 속도, 유형별 안내
- BottomCTA — 화면 하단 고정 액션 영역
- Button — `이 요금제로 변경하기`, 다시 불러오기, 목록 이동
- 신규: Detail Skeleton — 상세 로딩 자리 표시자
- 신규: Empty State — 존재하지 않는 요금제 안내
- 신규: Inline Error — 상세 조회 실패 안내

### 상태
- 기본: 요금 요약과 데이터 조건을 표시한다. 할인 금액은 `regular_price − promo_price`로 계산하고 변경 Button은 활성화한다.
- 로딩: Detail Skeleton을 표시하고 변경 Button을 비활성화한다.
- 빈: 요금제가 없으면 `요금제를 찾을 수 없어요.`와 목록 이동 Button을 표시한다.
- 에러: `요금제 정보를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`와 다시 불러오기 Button을 표시한다.

### 이동
- 들어오는 곳: 요금제 목록, 변경 전 확인, 변경 신청
- 나가는 곳: 뒤로 가기 → 필터를 유지한 요금제 목록, 변경 Button → 변경 전 확인

## 변경 전 확인

### 목적
신청 직전에 이번 달 요금·위약금·유심 교체 안내를 확인한다. 금액 계산 결과는 표시하지 않는다. US4를 해결한다.

### 라우트
`/plans/:planId/confirm`

### 구성 요소
- Header — 화면 제목
- icon/arrowLeft — 요금제 상세로 돌아가기
- Card/Plan — 요금제 이름, 매달 내는 돈, 24개월 후 월 요금
- List/Row — 이번 달 요금, 위약금, 유심 교체 안내
- BottomCTA — 하단 버튼 영역
- Button — `신청하기`, `다른 요금제 보기`, 다시 불러오기
- 신규: Confirm Skeleton — 선택 요금제와 안내 항목 로딩 자리 표시자
- 신규: Empty State — 선택 요금제 정보 없음 안내
- 신규: Inline Error — 확인 정보 조회 실패 안내

### 상태
- 기본: 선택 요금제와 안내 3개를 모두 펼쳐 표시한다. 이번 달 요금과 위약금에는 숫자 금액을 표시하지 않는다.
- 로딩: Confirm Skeleton을 표시하고 하단 Button을 비활성화한다.
- 빈: 요금제 정보가 없으면 `선택한 요금제 정보가 없어요.`와 목록 이동 Button을 표시한다.
- 에러: `변경 전 안내를 불러오지 못했어요. 잠시 후 다시 시도해 주세요.`와 다시 불러오기 Button을 표시한다.

### 이동
- 들어오는 곳: 요금제 상세
- 나가는 곳: 뒤로 가기 → 요금제 상세, 신청하기 → 변경 신청, 다른 요금제 보기 → 요금제 목록

## 변경 신청

### 목적
이름, 휴대폰 번호, 개인정보 수집·이용 동의를 입력받아 요금제 변경 신청 1건을 저장한다. US4를 해결한다.

### 라우트
`/plans/:planId/apply`

### 구성 요소
- Header — 화면 제목과 상단 취소
- Button — 상단 `취소`
- Card/Plan — 요금제 이름과 매달 내는 돈
- Input — 이름 입력과 오류 문구
- Input — 휴대폰 번호 입력과 오류 문구
- OptionItem — 개인정보 수집·이용 동의 행
- Checkbox — 필수 동의 선택
- Button — 개인정보 수집·이용 내용 `보기`
- 신규: Privacy Bottom Sheet — 수집 항목, 이용 목적, 보관 기간
- BottomCTA — 하단 고정 제출 영역
- Button — `신청 완료하기`, 비활성·활성·로딩 상태
- 신규: Application Skeleton — 신청 요금제 로딩 자리 표시자
- 신규: Inline Error — 저장 실패 안내

### 상태
- 기본: Input 2개는 빈 값이고 Checkbox는 해제 상태다. 이름, 휴대폰 번호, 동의를 모두 충족하기 전까지 제출 Button은 비활성화한다.
- 로딩: 제출 Button을 로딩·비활성 상태로 전환하고 `Subscription`을 `received` 상태로 저장한다.
- 빈: 이름이나 휴대폰 번호가 비어 있거나 동의하지 않은 상태다. 포커스가 빠지면 각 Input에 오류 문구를 표시한다.
- 에러: 이름 20자 초과 또는 휴대폰 번호 형식 오류를 Input에 표시한다. 저장 실패 시 입력값을 유지하고 제출 Button을 다시 활성화한다.

### 이동
- 들어오는 곳: 변경 전 확인
- 나가는 곳: 저장 성공 → 신청 완료, 취소 → 입력값 삭제 후 요금제 상세

## 신청 완료

### 목적
저장 직후 신청 번호와 방금 신청한 1건의 내용을 확인한다. 이후 재조회 기능은 제공하지 않는다. US5를 해결한다.

### 라우트
`/subscriptions/complete`

### 구성 요소
- icon/doneMark — 신청 접수 완료 표시
- Header — `요금제 변경 신청이 접수됐어요`
- List/Row — 신청 번호와 복사 액션
- Button — 신청 번호 복사
- Card/Plan — 요금제 이름과 매달 내는 돈
- List/Row — 이름, 휴대폰 번호, 신청 일시, 처리 상태
- Tag — 처리 상태 `접수 완료`
- 신규: Caution Notice — 재조회 불가 및 신청 번호 복사 안내
- 신규: Toast — `신청 번호를 복사했어요.`
- BottomCTA — 하단 고정 액션 영역
- Button — `처음으로`, 완료 정보 다시 확인
- 신규: Completion Skeleton — 저장 결과 로딩 자리 표시자
- 신규: Empty State — 완료 데이터 없음 안내
- 신규: Inline Error — 완료 정보 표시 실패 안내

### 상태
- 기본: 신청 번호 1개와 방금 저장한 신청 1건만 표시한다. 휴대폰 번호는 `010-****-1234` 형식으로 표시한다. 복사 후 Toast를 2초간 표시한다.
- 로딩: Completion Skeleton을 표시하고 복사 및 처음으로 Button을 비활성화한다.
- 빈: 신청 정보가 없으면 `확인할 신청 정보가 없어요.`와 처음으로 Button만 표시한다.
- 에러: `신청은 접수됐지만 내용을 표시하지 못했어요. 처음 화면으로 이동해 주세요.`를 표시한다. 재저장 기능은 제공하지 않는다.

### 이동
- 들어오는 곳: 변경 신청 저장 성공 직후
- 나가는 곳: 처음으로 또는 브라우저 뒤로 가기 → 요금제 목록
