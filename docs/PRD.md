# PRD.md — 요금제 추천·구독 서비스

이 문서는 AI 인터뷰 결과로 채웠다. 6개 섹션의 순서와 제목은 바꾸지 않는다. 색·글자·간격·컴포넌트 같은 비주얼 규칙은 여기에 쓰지 않고 Design.md를 따른다.

---

## 1. 목적

### 한 줄 정의

요금제 추천은 매달 데이터가 부족하거나 약정이 끝난 고객이 요금제별 속도 제한 여부와 매달 실제로 내는 돈을 비교해, 매장에 가지 않고 이름·휴대폰 번호·동의만으로 요금제 변경을 신청하는 모바일 웹 서비스다.

### 해결할 문제

1. 출퇴근길에 영상을 보는 고객은 매달 20일쯤 데이터가 다 떨어진다.
2. 통신사 앱·홈페이지에 요금제가 20개 넘게 나열되고, "무제한"이라는 이름만으로는 기본 데이터 소진 후 속도가 제한되는 요금제와 속도 제한이 없는 요금제를 구분할 수 없다. 정가·할인가·프로모션가가 함께 표시되어 매달 실제로 내는 돈과 24개월 프로모션 종료 후 금액도 알 수 없다. 그래서 고객은 요금제를 몇 개 눌러보다 포털 검색과 커뮤니티 후기로 이탈한다.
3. 요금제를 골라도 신청 절차(본인 인증, 약관 동의, 유심 교체 여부)가 복잡할 것 같고 이번 달 요금 계산과 위약금 여부가 불확실해 "주말에 매장 가서 할게요" 하고 신청을 미룬다. 신청한 고객은 "신청한 게 제대로 된 거 맞아요? 문자가 안 왔어요"라는 확인 문의를 가장 많이 한다.

---

## 2. 대상 사용자

### 유저 스토리

- **US1.** 매달 20일쯤 데이터가 떨어지는 고객으로서, 20개가 넘는 요금제 중 내 사용 패턴에 맞는 후보만 좁혀 보고 싶다. 왜냐하면 요금제를 하나씩 눌러보다 지쳐서 포털 검색으로 넘어가게 되기 때문이다.
- **US2.** "무제한" 요금제를 고르는 고객으로서, 기본 데이터를 다 쓴 뒤 속도가 제한되는 요금제인지 속도 제한이 없는 요금제인지 구분하고 싶다. 왜냐하면 "무제한이라면서 왜 느려져요?" 같은 상황을 다시 겪고 싶지 않기 때문이다.
- **US3.** 요금제를 고른 고객으로서, 매달 실제로 내는 돈과 24개월 프로모션이 끝난 뒤 금액을 알고 싶다. 왜냐하면 정가·할인가·프로모션가가 섞여 있으면 내가 얼마를 내게 될지 판단할 수 없기 때문이다.
- **US4.** 신청을 망설이는 고객으로서, 이번 달 요금·위약금·유심 교체에 대한 안내를 확인한 뒤 매장에 가지 않고 그 자리에서 신청을 끝내고 싶다. 왜냐하면 절차가 복잡하거나 위약금이 확실하지 않으면 신청을 미루게 되기 때문이다.
- **US5.** 신청을 마친 고객으로서, 신청이 접수됐는지 그 자리에서 확인하고 싶다. 왜냐하면 접수 여부를 모르면 고객센터에 다시 문의하게 되기 때문이다.

### 사용자 상황

- 출퇴근길마다 영상을 보는 고객은 매달 20일쯤 데이터가 떨어지고, 약정 만료 문자를 받거나 지인이 같은 돈으로 더 좋은 요금제를 쓴다는 이야기를 들으면 요금제 변경을 생각한다.
- 통신사 앱의 요금제 페이지를 먼저 열지만 20개 넘는 요금제를 몇 개 눌러보다 차이를 알 수 없어 포털에서 "데이터 무제한 요금제 추천"을 검색하거나 커뮤니티 후기를 찾는다.
- "무제한"이 속도 제한형인지 구분되지 않고, 정가·할인가·프로모션가가 함께 있어 매달 실제로 내는 돈과 24개월 후 금액을 모른다.
- 겨우 하나를 골라도 신청 절차와 이번 달 요금 계산, 위약금 여부가 불확실해 "주말에 매장 가서 할게요" 하고 미룬다.
- 신청한 고객은 완료 문자가 오지 않으면 "제대로 된 거 맞아요?"라고 고객센터에 문의한다.

## 3. 화면 목록

지켜야 할 것: ① 화면 5개 ② "신청(저장)" 흐름 1개 포함(4번 화면) ③ 모든 화면은 샘플 라이브러리 컴포넌트와 토큰으로만 구성한다.

### 화면 구조

**[화면 1] 요금제 목록**
- 한 줄 역할: 무제한 유형 필터로 요금제 후보를 좁히고, 카드에서 유형·데이터·매달 내는 돈을 비교한다.
- 해결하는 유저 스토리: US1, US2

**[화면 2] 요금제 상세**
- 한 줄 역할: 선택한 요금제의 요금 구성(정가 − 할인 = 매달 내는 돈), 24개월 후 월 요금, 기본 데이터 소진 후 속도 조건을 확인한다.
- 해결하는 유저 스토리: US2, US3

**[화면 3] 변경 전 확인**
- 한 줄 역할: 신청 직전에 이번 달 요금·위약금·유심 교체에 대한 안내 문구를 확인한다. 금액 계산은 하지 않는다.
- 해결하는 유저 스토리: US4

**[화면 4] 변경 신청 (신청/저장 흐름)**
- 한 줄 역할: 이름, 휴대폰 번호, 개인정보 수집·이용 동의 1개를 입력받아 신청을 저장한다. 본인 인증과 로그인은 없다.
- 해결하는 유저 스토리: US4

**[화면 5] 신청 완료**
- 한 줄 역할: 저장 직후 신청 번호와 방금 신청한 1건의 내용을 확인한다. 나중에 다시 조회하는 기능은 없다.
- 해결하는 유저 스토리: US5 (완료 직후 확인 범위까지)

### 주요 흐름

```
진입 → 요금제 목록 → 요금제 상세 → 변경 전 확인 → 변경 신청 → 신청 완료 → 끝
```

되돌아가는 흐름:
- 요금제 상세 → (뒤로) → 요금제 목록 (선택했던 필터 유지)
- 변경 전 확인 → (뒤로) → 요금제 상세
- 변경 신청 → (취소) → 요금제 상세 (입력값 삭제)
- 신청 완료 → (처음으로 / 뒤로) → 요금제 목록 (신청 화면으로 돌아가지 않음)

## 4. 화면별 기능

### 4-1. 요금제 목록

필수 기능:

1. **화면 제목**
   - 표시 항목: 제목 "나에게 맞는 요금제 찾기", 보조 문구 "무제한 유형과 매달 내는 돈을 비교해 보세요."
2. **무제한 유형 필터 칩**
   - 표시 항목: 칩 4개 — `전체` / `기본형` / `무제한 · 속도 제한 있음` / `완전 무제한`
   - 기본 상태: `전체` 선택, 요금제 4개 전부 표시
   - 동작: 칩은 1개만 선택된다(단일 선택). 칩을 탭하면 해당 `type`의 카드만 남고, 정렬 순서는 유지된다. 해당 유형 요금제가 0개면 카드 영역에 "이 유형의 요금제가 없어요." 문구를 표시한다.
3. **요금제 카드**
   - 표시 항목: 요금제 이름, 유형 라벨(`기본형` / `무제한 · 속도 제한 있음` / `완전 무제한`), 기본 데이터량, 소진 후 속도, 매달 내는 돈(`promo_price`), 보조 문구 "24개월 후 월 OO원"(`regular_price`), 한 줄 설명
   - 기본 상태: 매달 내는 돈 낮은 순으로 정렬(p01 → p02 → p03 → p04)
   - 규칙: 카드 안 금액은 "매달 내는 돈"과 "24개월 후 월 요금" 2개만 표시한다. 정가 취소선, 할인 금액, 할인율은 카드에 표시하지 않는다.
4. **추천 배지**
   - 표시 항목: `is_recommended = true`인 요금제 카드 1개에만 "추천" 배지
   - 기본 상태: 실습 데이터 기준 p03에 표시. 필터로 p03이 숨겨지면 배지도 화면에서 사라진다.
5. **카드 탭**
   - 동작: 카드 전체 영역을 탭하면 해당 요금제 `id`로 요금제 상세로 이동한다.

### 4-2. 요금제 상세

필수 기능:

1. **요금 요약**
   - 표시 항목: 요금제 이름, 유형 라벨, 추천 배지(`is_recommended = true`일 때만), "매달 내는 돈" 금액, 기간 문구 "가입 후 24개월 동안", "24개월 후 월 OO원"
   - 기본 상태: 진입 시 상단에 고정 노출
2. **요금 구성**
   - 표시 항목: 3줄 고정 형식 — `정가 월 OO원` / `24개월 할인 −OO원` / `매달 내는 돈 월 OO원`
   - 규칙: 할인 금액 = `regular_price − promo_price`. 금액 이름은 "정가", "24개월 할인", "매달 내는 돈" 3가지만 쓴다. "할인가", "프로모션가"라는 단어는 쓰지 않는다.
3. **데이터 조건**
   - 표시 항목: 기본 데이터량, 소진 후 속도, 유형별 고정 안내 문구
     - `basic`: "기본 데이터 {data}를 다 쓰면 이번 달 남은 기간 동안 최대 {speed_after}로 느려져요."
     - `limited_unlimited`: "이름에 '무제한'이 있지만 기본 데이터 {data}를 다 쓰면 이번 달 남은 기간 동안 최대 {speed_after}로 느려져요."
     - `full_unlimited`: "기본 데이터 한도와 속도 제한이 없어요."
4. **변경 버튼**
   - 표시 항목: 화면 하단 고정 버튼 "이 요금제로 변경하기"
   - 기본 상태: 활성
   - 동작: 탭하면 같은 요금제 `id`로 변경 전 확인으로 이동한다.
5. **뒤로 가기**
   - 동작: 요금제 목록으로 이동하고, 이전에 선택한 필터 칩 상태를 유지한다.

### 4-3. 변경 전 확인

필수 기능:

1. **선택 요금제 요약**
   - 표시 항목: 요금제 이름, 매달 내는 돈, 24개월 후 월 요금
2. **변경 전 안내 3항목**
   - 표시 항목: 아래 3개 항목을 제목 + 안내 문구로 표시. 숫자 금액은 표시하지 않는다.
     - 이번 달 요금: "이번 달 요금은 변경이 처리되는 날짜에 따라 달라질 수 있어요. 정확한 금액은 다음 달 청구서에서 확인할 수 있어요."
     - 위약금: "약정 기간 중에 요금제를 바꾸면 위약금이 생길 수 있어요. 약정이 끝났다면 위약금 없이 바꿀 수 있어요."
     - 유심 교체: "요금제만 바꾸는 경우 지금 쓰는 유심을 그대로 쓸 수 있어요."
   - 기본 상태: 3개 항목 모두 펼친 상태. 접기/펼치기 없음.
   - ※ 위 문구는 초안이다. 실제 요금·위약금·유심 정책 확인 후 문구를 확정한다.
3. **하단 버튼**
   - 표시 항목: 주 버튼 "신청하기", 보조 버튼 "다른 요금제 보기"
   - 동작: "신청하기" → 같은 요금제 `id`로 변경 신청 이동. "다른 요금제 보기" → 요금제 목록 이동.

### 4-4. 변경 신청

필수 기능:

1. **신청 요금제 요약**
   - 표시 항목: 요금제 이름, 매달 내는 돈
2. **입력 필드 2개**
   - 이름: 텍스트 입력, 플레이스홀더 "이름", 1~20자
   - 휴대폰 번호: 숫자 키패드, 플레이스홀더 "010-0000-0000", 숫자 11자리 입력 시 하이픈 자동 삽입
   - 기본 상태: 두 필드 모두 빈 값
3. **동의 체크박스 1개**
   - 표시 항목: "[필수] 개인정보 수집·이용에 동의합니다", 오른쪽 "보기" 링크
   - 기본 상태: 체크 해제
   - 동작: "보기"를 탭하면 수집 항목(이름, 휴대폰 번호)·이용 목적(요금제 변경 신청 처리)·보관 기간을 바텀시트로 띄운다. 바텀시트를 닫아도 체크 상태는 바뀌지 않는다.
4. **신청 버튼**
   - 표시 항목: 하단 고정 버튼 "신청 완료하기"
   - 기본 상태: 비활성
   - 활성 조건: 이름 1자 이상 AND 휴대폰 번호 형식 통과 AND 동의 체크
   - 동작: 탭하면 버튼이 비활성+로딩 상태로 바뀌고(중복 제출 방지) `Subscription`을 `status = received`로 저장한다. 저장 성공 시 신청 완료로 이동한다.
5. **취소**
   - 표시 항목: 상단 "취소"
   - 동작: 탭하면 입력값을 지우고 요금제 상세로 이동한다.

오류 상황과 안내 문구:

| 상황 | 판정 시점 | 안내 문구 | 처리 |
|---|---|---|---|
| 이름 빈 값 | 이름 필드에서 포커스가 빠질 때 | "이름을 입력해 주세요." | 필드 아래 문구 표시, 버튼 비활성 유지 |
| 이름 20자 초과 | 입력 중 | "이름은 20자까지 입력할 수 있어요." | 21번째 글자부터 입력 막음 |
| 휴대폰 번호 형식 오류 (010으로 시작하는 숫자 11자리가 아님) | 휴대폰 필드에서 포커스가 빠질 때 | "휴대폰 번호 11자리를 정확히 입력해 주세요." | 필드 아래 문구 표시, 버튼 비활성 유지 |
| 저장 실패 (네트워크·서버 오류) | 신청 버튼 탭 후 | "신청을 완료하지 못했어요. 잠시 후 다시 시도해 주세요." | 입력값 유지, 버튼 다시 활성 |

### 4-5. 신청 완료

필수 기능:

1. **완료 메시지**
   - 표시 항목: 제목 "요금제 변경 신청이 접수됐어요"
2. **신청 번호**
   - 표시 항목: 신청 번호(`application_no`, 형식 `SUB-` + 6자리 숫자, 예: SUB-482913), 오른쪽 "복사" 버튼
   - 동작: "복사"를 탭하면 신청 번호를 클립보드에 복사하고 "신청 번호를 복사했어요." 토스트를 2초간 띄운다.
3. **신청 내용 1건**
   - 표시 항목: 요금제 이름, 매달 내는 돈, 이름, 휴대폰 번호(가운데 4자리 마스킹, 예: 010-****-1234), 신청 일시(YYYY.MM.DD HH:mm), 처리 상태 "접수 완료"
   - 규칙: 방금 저장한 1건만 표시한다. 목록·검색·다른 신청 내역은 없다.
4. **보관 안내**
   - 표시 항목: "이 화면을 닫으면 신청 내용을 다시 조회할 수 없어요. 신청 번호를 복사해 두세요."
5. **처음으로 버튼**
   - 표시 항목: 하단 버튼 "처음으로"
   - 동작: 요금제 목록으로 이동한다. 이 화면에서 브라우저 뒤로 가기를 해도 요금제 목록으로 이동하며, 변경 신청 화면으로 돌아가거나 다시 저장되지 않는다.

### 요금제 데이터

요금제 목록·요금제 상세·변경 전 확인·변경 신청·신청 완료 화면에서 쓰는 실습용 가상 데이터 4개. 실제 통신사 요금제가 아니다.

| id | 이름 | 월 요금 (정가) | 매달 내는 돈 (24개월) | 데이터 | 소진 후 속도 | 유형 (type) | 추천 | 한 줄 설명 |
|---|---|---|---|---|---|---|---|---|
| p01 | 라이트 7 | 39,000원 | 32,000원 | 7GB | 400kbps | basic (기본형) | - | 영상보다 메신저·검색 위주로 쓰는 분께 맞는 요금제 |
| p02 | 출퇴근 50 | 55,000원 | 47,000원 | 50GB | 1Mbps | limited_unlimited (무제한 · 속도 제한 있음) | - | 출퇴근길에 짧은 영상을 매일 보는 분께 맞는 요금제 |
| p03 | 데일리 무제한 110 | 69,000원 | 59,000원 | 110GB | 5Mbps | limited_unlimited (무제한 · 속도 제한 있음) | ✓ | 출퇴근길 영상 시청이 길어 월말 전에 데이터가 떨어지는 분께 맞는 요금제 |
| p04 | 프리 무제한 | 89,000원 | 79,000원 | 제한 없음 | 제한 없음 | full_unlimited (완전 무제한) | - | 데이터 한도와 속도 제한 없이 쓰고 싶은 분께 맞는 요금제 |

- 24개월 할인 금액 = 정가 − 매달 내는 돈 (p01 7,000원 / p02 8,000원 / p03 10,000원 / p04 10,000원)
- 추천은 이번 범위에서 고정값이다(개인별 계산 없음).

### 어기면 안 되는 것

완성 화면을 보고 O/X로 판정한다.

1. 추천 배지는 요금제 목록에 1개만 보인다.
2. 이름에 "무제한"이 들어간 요금제 카드에는 `무제한 · 속도 제한 있음` 또는 `완전 무제한` 라벨이 반드시 붙어 있다.
3. 요금제 목록 카드 1개에 표시되는 금액은 "매달 내는 돈"과 "24개월 후 월 요금" 2개뿐이다.
4. 서비스 전체 화면에 "할인가", "프로모션가"라는 단어가 없다.
5. 변경 전 확인 화면에 이번 달 요금·위약금 관련 숫자 금액(원 단위)이 없다.
6. 변경 신청 화면의 입력 요소는 이름 필드 1개, 휴대폰 번호 필드 1개, 동의 체크박스 1개뿐이다.
7. 이름·휴대폰 번호·동의 중 하나라도 비어 있으면 "신청 완료하기" 버튼이 비활성이다.
8. 서비스 어느 화면에도 로그인, 본인 인증, 결제 화면이 없다.
9. 신청 완료 화면에 신청 번호가 1개 표시되고, 휴대폰 번호 가운데 4자리가 `****`로 가려져 있다.

## 5. 데이터

```
Plan (요금제)                      # 4장 요금제 데이터. 이번 범위에서는 고정 데이터로 읽기만 함
  id                text           # p01 ~ p04
  name              text
  regular_price     integer        # 정가(원), 24개월 후 월 요금
  promo_price       integer        # 매달 내는 돈(원), 가입 후 24개월
  promo_months      integer        # 24
  data_gb           integer | null # null = 제한 없음
  speed_after       text | null    # 소진 후 속도, null = 제한 없음
  type              text           # type: basic / limited_unlimited / full_unlimited
  is_recommended    boolean        # true는 1개만
  description       text           # 한 줄 설명

Subscription (구독 신청)
  id                uuid
  application_no    text           # SUB-000000 형식, 중복 불가
  name              text           # 1~20자
  phone             text           # 숫자 11자리, 010으로 시작 (하이픈 없이 저장)
  plan_id           text           # 4장 요금제 데이터의 id
  privacy_agreed    boolean        # 항상 true (미동의 시 저장 불가)
  status            text           # status: received / processing / completed / canceled
                                   # 이번 범위에서는 received로만 생성
  created_at        timestamptz
```

## 6. 범위 밖

### 이번에 안 함

- 결제
- 본인 인증 · 로그인
- 관리자 화면
- 이번 달 요금 · 위약금 금액 계산 (안내 문구로 대체)
- 신청 상태 변경 처리 (`processing` / `completed` / `canceled`)

### 다음 단계 후보

- **신청 내역 재조회**: 나중에 다시 들어와 신청 번호와 휴대폰 번호로 처리 상태를 확인하는 화면. 인터뷰에서 가장 많았던 "신청한 게 제대로 된 거 맞아요? 문자가 안 왔어요" 문의(US5)를 완료 화면 이후까지 해결한다.
- **이번 달 요금 · 위약금 계산**: 안내 문구 대신 고객별 예상 금액을 표시한다. 인터뷰에서 위약금이 확실하지 않으면 신청을 멈춘다는 문제(US4)를 더 직접적으로 해결한다.
