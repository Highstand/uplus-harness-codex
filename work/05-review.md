## 5. 저장 제외 범위와 연결 설계

lib/demo.ts는 모듈 메모리 session과 React 구독으로 결과를 유지한다. ApplicationInput, DemoReceipt, completeDemo()로 이후 저장 연결 지점을 분리한다.

앞선 소스 검토에서 신청용 서버 API 호출, Supabase, localStorage, sessionStorage 사용을 발견하지 않았다. 완료 화면은 실제 접수가 아닌 시연임을 명시한다.

판정자가 네트워크 전체 기록을 수집한 것은 아니다. 비저장 검토 근거는 구현과 관찰한 메모리 수명 동작이다.
